# ISTC landing pages

Two static landing pages about the International Science and Technology Center (ISTC).

- `index.html` — ISTC overview: story, mission, areas of interest, who we work with, governance, offices, FAQ.
- `projects/` — ISTC projects: the 8-stage project route, ten featured programmes (Annual Report 2024), charts and a searchable database of 463 projects from istc.int/projects.

Facts come from istc.int and the ISTC Annual Report 2024. Data and vector art are generated by `_source/site_build.py` in the parent project; HTML/CSS/JS here are hand-written. No build step — open `index.html` or serve the folder.
